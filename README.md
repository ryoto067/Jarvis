# ジャービス（J.A.R.V.I.S.）

声で呼び出して、Claude Code を操作できる音声アシスタントです。自分の PC の中だけで動き、ほかの人や端末からは見られません。API キー不要・追加料金なしで、Claude の契約プランの使用量を使います。

## 起動のしかた
1. このフォルダの `start.bat` をダブルクリックする
2. ブラウザ（Chrome か Edge）で http://127.0.0.1:8765 が開く
3. 「INITIALIZE」を押して、マイクを「許可」する

止めるときは、`start.bat` で開いた黒い画面（コマンドプロンプト）を閉じます。

## 呼び出し方
- 手を 2 回パンパンと叩く
- 「ジャービス」「Hi ジャービス」「Hey ジャービス」「ねえねえジャービス」「おいジャービス」「OK ジャービス」など
- 「Hi ジャービス、今何時？」のように、呼びかけと用件を一度に言ってもよい
- 画面下の入力欄に文字で打ってもよい

## 終わりの合図
「終了」と言うとスタンバイに戻ります。それ以外の言葉や時間切れでは終わりません。

## 秘書として使う
パーソナル秘書システム（`C:\Users\admin\.secretary\`）とつながっていて、タスク・メモ・予定・振り返りを声で頼めます。

| こう言うと | ジャービスがすること |
|---|---|
| （その日はじめて INITIALIZE を押したとき） | 朝のブリーフィングを自動で行う |
| 「おはよう」「ブリーフィング」 | 今日の予定（Google カレンダー）・今日のタスク・返信が必要そうなメールを報告 |
| 「タスク追加〇〇」「〇〇やらなきゃ」 | 今日の TODO に追加して復唱 |
| 「今日のタスク」「何からやればいい？」 | 優先度の高い順に3つほど読み上げ |
| 「〇〇終わった」 | そのタスクを完了にする |
| 「メモ〇〇」「覚えておいて」 | inbox に時刻付きで記録 |
| 「アイデア〇〇」「調べておいて〇〇」 | ideas / research にファイルを作る（調査はウェブ検索して要点を書く） |
| 「予定入れて」 | 日時とタイトルを復唱して確認してから、カレンダーに登録 |
| 「今日の振り返り」 | 完了・未完了を報告し、未完了を明日に回すか確認。そのあと学びメモの質問を1問ずつ |
| 「週次レビュー」「ダッシュボード」「受信箱整理」 | 秘書システムのコマンドどおりに動く |

秘書フォルダへの追記は確認なしで行います。削除・上書き・外部への送信は、これまでどおり確認してから行います。

## うまく動かないとき
- **「Failed to authenticate」と出る**:Claude Code のログインが切れています。ターミナルで `claude auth login` を実行してログインし直してください。YouTube の自動作成も同じログインを使っています。

## できること
ふだんの Claude Code と同じことが全部できます。作業場所は拠点フォルダ（`Desktop\claude`）なので、CLAUDE.md・専門エージェント・スキルもそのまま効きます。

- 雑談・相談・調べもの（天気やニュースはウェブ検索）
- ファイルを読む・書く・コマンドを実行する
- Gmail・Google カレンダー・Google Drive・Slack・Notion の操作
- 「YouTube 開いて」のようにブラウザでページを開く

## 安全のための決まり
- メールや Slack の送信、投稿、削除、公開、支払いの前には、ジャービスが必ず内容を読み上げて「よろしいですか？」と確認します。「はい」と答えるまで実行しません。
- Claude Code は「auto」モードで動きます。明らかに危険な操作は Claude Code 自身が止めます。止められた操作は、VS Code の Claude Code から直接頼んでください。
- 作業中に「ジャービス、中止」と言うと作業を止めます。

## 声
画面左の「音声」から選べます。初期設定は VOICEVOX の「青山龍星」です。VOICEVOX が使えないときは、自動で Windows の声に切り替わります。

- VOICEVOX は、YouTube の自動作成（`projects/youtube/money/`）と同じエンジンを使っています。アップデートや入れ直しをするときは、YouTube 側にも影響する点に気をつけてください。
- 動画などで公開するときは「VOICEVOX:青山龍星」のような表記が必要です。

## ファイルの中身
| ファイル | 役割 |
|---|---|
| `index.html` | 画面（円や波形の表示・音声認識・読み上げ） |
| `server.js` | ローカルサーバー（Claude Code と VOICEVOX へのつなぎ役） |
| `start.bat` | 起動用 |
| `package.json` | Node.js の設定（追加で入れる部品はなし） |

## 気になる点
- 「〇〇開いて」でページが開かないときは、ブラウザのポップアップを許可してください。
- 時間のかかる作業を頼むほど、Claude Code の使用量を多く消費します。
- ジャービスでの会話は、ふだんの Claude Code と同じく作業の記録として残ります。
